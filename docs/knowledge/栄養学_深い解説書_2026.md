# 食材から身体へ
## 五大栄養素と「33項目」を読み解く栄養学・実践解説書

**2026年10月版｜基礎教材8ページの内容を再構成し、科学的な補足・訂正を加えた独立解説書**

> この本の基本原則は、「食材に栄養素が含まれる」ことと、「必要な量を食べ、吸収・利用でき、健康上の利益が得られる」ことを区別する、という一点にある。

**参照基準：** 厚生労働省『日本人の食事摂取基準（2025年版）』、文部科学省『日本食品標準成分表（八訂）増補2023年』。一般の健康な成人を中心に解説し、妊娠・授乳、成長期、高齢者、持病や服薬のある人については例外を明示する。数値は集団に基づく基準であり、個人の診断値ではない。

# 序章　栄養学は「食べ物当てクイズ」ではない

教材には、肉・魚・卵にはたんぱく質、油・アボカド・ナッツには脂質、米・パン・芋には炭水化物、野菜・果物にはビタミン、牛乳・小魚・海藻にはミネラルという整理がある。入口として非常に便利だが、そのまま献立を評価すると誤りやすい。たとえば、ほうれん草に鉄が含まれていても、鉄の供給源として十分かは食べる量と吸収率で変わる。ナッツはビタミンEの供給源になり得るが、脂質とエネルギーも多い。海藻はミネラルを含むが、昆布などではヨウ素が過剰になる可能性もある。

実際の評価は、**①食品の可食部量 → ②調理後に残る成分 → ③消化・吸収 → ④体内での利用 → ⑤不足・過剰や健康状態との関係**を順番に考える必要がある。栄養学とは、食品名を五大栄養素に振り分ける作業ではなく、身体に届く量と作用を見積もる学問である。

また、栄養素の重要性は「1日」だけで確定しない。エネルギーとたんぱく質は日々の不足が問題になりやすい一方、蓄積される栄養素や食習慣に関係する評価は、数日から数週間の食事全体を見るほうが適切な場合がある。

# 第1章　「五大栄養素」と「33項目」の正確な関係

## 1-1　分類の構造

五大栄養素は**たんぱく質・脂質・炭水化物・ビタミン・ミネラル**の五群である。前の三つは主にエネルギーを産生する「三大栄養素」で、後の二つは少量で身体の反応を成立させる重要な成分群だ。ただし、たんぱく質は身体の材料、脂質は細胞膜の材料でもあり、役割は一つではない。

教材の「33種類」という数え方は、五大栄養素の下に設ける**栄養評価上の項目**を指している。

| 項目のまとまり | 内訳 | 数 |
|---|---|---:|
| たんぱく質 | たんぱく質 | 1 |
| 脂質関係 | 脂質、飽和脂肪酸、n-3系脂肪酸、n-6系脂肪酸 | 4 |
| 炭水化物関係 | 炭水化物、食物繊維 | 2 |
| ビタミン | A、D、E、K、B1、B2、B6、B12、ナイアシン、パントテン酸、ビオチン、葉酸、C | 13 |
| ミネラル | Na、K、Ca、Mg、P、Fe、Zn、Cu、Mn、I、Se、Cr、Mo | 13 |
| **合計** | **教材で扱う分類項目** | **33** |

**重要な訂正：** これは「33個すべてが互いに独立した必須栄養素」「33種類すべてを増やすべき」という意味ではない。飽和脂肪酸は脂質の一部で、むしろ摂り過ぎの抑制が課題となる。食物繊維は健康上重要だが、古典的な「欠乏症が生じる必須栄養素」とは違う。クロムは日本の基準に項目がある一方、人体に必須かどうか国際的には議論が残る。水も生命維持に不可欠だが、この「33」には含まれていない。

## 1-2　栄養摂取基準の数値を読み違えない

「日本人の食事摂取基準（2025年版）」には、役割の異なる指標が並ぶ。**推定平均必要量（EAR）**は集団の約半数の必要量を満たす水準、**推奨量（RDA）**は大多数の必要量を満たすと見込む水準、**目安量（AI）**は必要量を十分に推定できないときに設定する水準、**目標量（DG）**は生活習慣病の予防を考慮した目標、**耐容上限量（UL）**は過剰摂取リスクを判断するための値である。

したがって「推奨量の半分しか摂れなかった日は直ちに欠乏症」「目安量を1gでも超えたら危険」「耐容上限量まで摂るほど健康的」という解釈は、いずれも誤りである。特に上限量は**目指す数値ではない**。

# 第2章　エネルギーとPFCバランス

## 2-1　三大栄養素の熱量

食事のエネルギーを簡便に計算する際は、たんぱく質**4kcal/g**、脂質**9kcal/g**、炭水化物**約4kcal/g**を用いる。これは一般的な換算係数であり、食物繊維の発酵や食品ごとの利用可能エネルギーを精密に表すものではない。食品成分表（八訂）のエネルギー計算には食品の成分に応じた方法が用いられるため、表示値と「4・9・4」の手計算は一致しないことがある。

PFCとはProtein（たんぱく質）、Fat（脂質）、Carbohydrate（炭水化物）のエネルギー構成割合を指す。**重量の割合ではない**。

## 2-2　一般的な成人の基準と計算例

18〜49歳の目標量の目安は、たんぱく質**13〜20%エネルギー**、脂質**20〜30%エネルギー**、炭水化物**50〜65%エネルギー**。なお、50〜64歳ではたんぱく質14〜20%、65歳以上では15〜20%とされ、年齢で異なる。

仮に1日2,000kcalで、P17%・F25%・C58%を選ぶと、次のようになる。

| 栄養素 | 計算 | 目安量 |
|---|---|---:|
| P | 2,000×0.17÷4 | **85g** |
| F | 2,000×0.25÷9 | **約56g** |
| C | 2,000×0.58÷4 | **290g** |

上の割合は100%になる。しかし、この食事が自動的に「健康的」になるわけではない。たとえば脂質25%でも、その大部分が飽和脂肪酸なら改善余地がある。炭水化物58%でも、食物繊維が少なく糖類に偏っていれば望ましくない。PFCが合っていても、鉄・カルシウム・ビタミンDが不足する可能性は十分ある。

**実務上の優先順位は、①その人に見合う総エネルギー、②必要なたんぱく質量、③脂質の量と質、④炭水化物の量と質、⑤食物繊維・微量栄養素**。パーセントだけを先に合わせない。

## 2-3　総エネルギーは人ごとに違う

必要エネルギーは年齢、身体活動、体格、身体状況で変わる。2025年版の成人の参考値は幅が大きく、たとえば18〜29歳女性は身体活動レベル「低い／普通／高い」で1,700／1,950／2,250kcal/日とされる。これは個人の確定値ではない。体重変化、活動量、空腹感、身体機能などと照らして見直す。

# 第3章　たんぱく質：食べる量だけでなく、アミノ酸と利用を見る

たんぱく質はアミノ酸がつながった物質で、筋肉だけでなく酵素、輸送たんぱく質、抗体、皮膚などを構成する。食事由来のたんぱく質は消化されてアミノ酸・小ペプチドとして吸収され、体内で必要な構成成分に再利用される。

人体のたんぱく質合成で使われる主なアミノ酸は20種類で、うち9種類は成人において食事から摂る必要がある**必須アミノ酸**。一つの必須アミノ酸が極端に少ないと、その食品だけでのたんぱく質利用に制約が生じ得る。卵、肉、魚、乳製品、大豆製品は良質なたんぱく質の供給源であり、穀物と豆を組み合わせる食事も有用である。毎食を厳密な「完全アミノ酸」にする必要はなく、日単位の食事の多様性が大切だ。

**18〜49歳のたんぱく質推奨量**は、基準上、男性65g/日、女性50g/日。ただし、これは誰にとっても最適な筋肉づくりの量という意味ではない。運動、体格、回復期、加齢などによって考え方は変わる。必要量の判断では、PFCの%だけでなく**g/日**を必ず見る。

卵1個にはおよそ6g程度、納豆1パックにはおよそ7〜9g程度、鶏肉や魚100gには概して十数〜20g超のたんぱく質が含まれるが、食品の種類、可食部、加工・調理状態によって変化する。食材の写真だけで「十分」とは判定できない。

エネルギー不足の食事では、たんぱく質が身体の材料として十分活用されないこともある。逆に、たんぱく質を増やすことだけに注目し、主食や野菜を減らしすぎてもバランスを損なう。

# 第4章　脂質：悪者でも万能薬でもない

脂質は1gで約9kcalを供給し、細胞膜の構造、エネルギー貯蔵、脂溶性ビタミンの吸収、ホルモン関連物質の材料に関わる。教材では油、アボカド、ナッツを例示するが、どの脂質をどの程度摂るかが本質である。

| 分類 | 主な食品・例 | 栄養学的な見方 |
|---|---|---|
| 飽和脂肪酸 | バター、肉の脂身、乳脂肪、ココナッツ油 | 成人の目標は総エネルギーの**7%以下**。多い分を不飽和脂肪酸に置き換える考え方が重要 |
| 一価不飽和脂肪酸 | オリーブ油、菜種油、アボカドなど | 脂質の質を改善する選択肢。ただしカロリーは変わらない |
| n-6系多価不飽和脂肪酸 | 大豆油、コーン油、くるみなど | 必須脂肪酸を含む。n-6を一律に「炎症の原因」として排除するのは不適切 |
| n-3系多価不飽和脂肪酸 | 青魚のEPA・DHA、えごま・亜麻仁のALA | 魚由来のEPA/DHAと植物由来のALAは同一物ではない。ALAからの変換は限定的 |
| トランス脂肪酸 | 一部加工油脂・食品など | 積極的な摂取は勧められない |

n-3系もn-6系も必要だが、単純な「n-6対n-3の黄金比」を万人に当てはめるより、**魚・ナッツ・植物油を適切に取り入れ、飽和脂肪酸に偏らない**実行可能な食事を考えたほうがよい。

脂質を極端に減らすと脂溶性ビタミンの摂取・吸収やエネルギー確保が難しくなり得る。一方、オリーブ油やナッツでも大量に食べれば総エネルギー過多になる。「良い油なら無制限」という理解は誤りである。

# 第5章　炭水化物と食物繊維：主食と糖の質を見分ける

炭水化物には消化吸収されやすい糖質と、消化されにくい食物繊維などがある。米・パン・芋に含まれるでんぷんは消化によって主にブドウ糖となり、身体の重要なエネルギー源になる。

脳は通常、ブドウ糖を大切な燃料として利用する。ただし、ここから「白砂糖を毎日食べなければ脳が動かない」とは結論できない。体内では糖新生が起こり、長い絶食などの条件下ではケトン体も利用される。**脳の燃料としてのブドウ糖の重要性と、砂糖・糖類の摂取必要性は別問題**である。

主食を比較する際には、炭水化物量だけでなく食物繊維、ビタミン・ミネラル、食べやすさ、量、調理状態も見る。白米が直ちに不健康というわけでも、玄米なら無条件に理想的というわけでもない。

## 5-1　食物繊維の働き

食物繊維は、腸内細菌に利用されるものや便の量・性状に関係するものなど、多様である。以前の「水溶性／不溶性」二分法は便利だが、粘性・発酵性・保水性などの性質でも違いが出る。食物繊維を急に増やすと腹部膨満を起こす人もいるため、摂取量は様子を見ながら増やす。

2025年版の目標量は、**18〜29歳で男性20g以上・女性18g以上、30〜49歳で男性22g以上・女性18g以上**。野菜だけで全量を稼ぐのではなく、豆類、きのこ、海藻、果物、全粒穀物などを組み合わせる。

# 第6章　ビタミン13種類：代謝を成立させる小さな部品

ビタミンは少量でも不可欠な働きを担う。脂溶性のA・D・E・Kと、水溶性のB群8種類・Cに分けられる（B群はB1、B2、B6、B12、ナイアシン、パントテン酸、ビオチン、葉酸）。ただし「水溶性ならいくら摂っても安全」は誤りで、一部は高用量のサプリメントによる有害作用がある。

## 6-1　脂溶性ビタミン4種類

| 名称 | 主要な機能 | 食事の供給源 | 誤解しやすい点 |
|---|---|---|---|
| **A** | 視覚サイクル、上皮・粘膜、免疫機能 | レバー、卵、緑黄色野菜のプロビタミンA | にんじんは主にβカロテン。ビタミンAは近視を治す薬ではない。レチノールの過剰摂取に注意 |
| **D** | カルシウム・リン代謝、骨の維持 | 魚類、卵黄、一部きのこ類 | 皮膚でも日光によって合成される。食品だけで供給量を見積もれない場合がある |
| **E** | 細胞膜などの酸化防御 | ナッツ、種子、植物油 | 「抗酸化＝大量に摂れば病気を防ぐ」とは言えない |
| **K** | 血液凝固因子と骨関連たんぱく質の活性化 | 納豆、葉物野菜 | 不足を防ぐことが重要。抗凝固薬ワルファリン使用中は摂取変動に特に注意 |

### 作用の連鎖：A・D・Kの実例

にんじんを油で調理すると、脂質によってカロテノイドの利用が改善する場合がある。ただし、摂取量が増えれば際限なく吸収されるわけではない。骨の健康では、カルシウムを食べることに加え、ビタミンDによる吸収調節や、ビタミンK、たんぱく質、身体活動なども関わる。特定の一栄養素を大量に取るだけの方法は合理的ではない。

## 6-2　水溶性ビタミン9種類

| 名称 | 生化学上の役割・不足時の問題 | 食事の供給源 |
|---|---|---|
| **B1（チアミン）** | 糖質由来のエネルギー代謝を支える補酵素。重度不足で脚気など | 豚肉、豆類、未精製穀物 |
| **B2（リボフラビン）** | FAD・FMNとして酸化還元反応に参加。口角炎などとの関連 | 乳製品、卵、魚、レバー、納豆 |
| **B6** | PLPとしてアミノ酸代謝、神経伝達物質合成に関与 | 魚、肉、いも、バナナなど |
| **B12** | 神経系の維持、造血・DNA合成に関与。欠乏で貧血・神経症状 | 魚介類、肉、乳製品、卵。植物中心の食事では特に要確認 |
| **ナイアシン** | NAD・NADPの材料としてエネルギー代謝・酸化還元 | 魚、肉、きのこ、落花生 |
| **パントテン酸** | 補酵素Aの材料として脂肪酸などの代謝 | 肉、卵、豆、きのこなど幅広い食品 |
| **ビオチン** | カルボキシラーゼ反応などに関与 | 卵、豆類、ナッツ、貝類など |
| **葉酸** | DNA合成、細胞分裂、正常な造血に関与 | 葉物野菜、枝豆、豆類、レバー |
| **C** | コラーゲン合成、抗酸化、非ヘム鉄の吸収促進 | パプリカ、ブロッコリー、果物、芋類 |

B1・B2・ナイアシンなどは、食べた栄養素からエネルギーを取り出す反応を助ける。しかし、ビタミン自身が目立ったカロリー源になるわけではない。**「疲れたからB群を多く飲めば必ず元気になる」ではなく、不足しているか、総エネルギーや睡眠など別の要因がないかを分ける**。

葉酸とB12は一緒に考える。両者とも正常な造血に関わり、B12欠乏は神経障害につながり得る。葉酸だけを大量に補うと、血液所見に現れるB12欠乏の一部の兆候が目立たなくなることがある。妊娠を計画している人などには、神経管閉鎖障害のリスク低減を目的として、通常の食事に加えてサプリメント等から葉酸400µg/日が推奨されるが、これはすべての人に一律にサプリメントを勧めるという話ではない。

**「ビタミンは体内で作れない」も正確には例外がある。** たとえばビタミンDは皮膚で合成でき、ナイアシンはトリプトファンからも合成される。腸内細菌が作るビタミンがあっても、それだけで必要量を十分に満たすとは限らない。

# 第7章　ミネラル13種類：不足だけでなく過剰を管理する

ミネラルは無機質で、骨・歯の材料、体液の調節、神経・筋肉の働き、酵素の材料などに関わる。教材の13項目は多量ミネラル5種類と微量ミネラル8種類に分けられる。「微量」は重要でないという意味ではなく、必要な量が少ないことを指す。

## 7-1　多量ミネラル5種類

| ミネラル | 重要な役割 | 食事の供給源 | 実践上の注意 |
|---|---|---|---|
| **ナトリウム Na** | 体液量、神経伝達、筋収縮 | 食塩、調味料、加工食品 | 不足より摂り過ぎが問題になりやすい。2025年版の食塩相当量目標は成人男性**7.5g未満**、女性**6.5g未満** |
| **カリウム K** | 細胞内の主要陽イオン、血圧・筋神経機能 | 豆、いも、野菜、果物 | 一般には積極的な食品摂取が有用。腎機能障害などでは摂取制限が必要なことがある |
| **カルシウム Ca** | 骨・歯、筋収縮、神経・血液凝固機能 | 牛乳・ヨーグルト、骨ごと食べる魚、豆腐、青菜 | 食品により吸収率が違う。ビタミンD不足、総摂取不足、運動不足も考慮 |
| **マグネシウム Mg** | 多数の酵素反応、筋神経機能、骨 | 豆、種子、ナッツ、全粒穀物、海藻 | 食品源を広げる。サプリメントによる過剰で下痢等に注意 |
| **リン P** | 骨、ATP、細胞膜 | 肉、魚、乳製品、豆、加工食品 | 普通の食事で不足は比較的まれ。加工食品のリン酸塩、腎疾患に注意 |

食塩相当量は食品に含まれるナトリウムから計算され、**食塩相当量(g) ≒ ナトリウム(mg)×2.54÷1,000**。たとえばナトリウム2,000mgは食塩相当量約5.1gである。塩を「ミネラル補給」のために余計に足す理由にはならない。

## 7-2　微量ミネラル8種類

| ミネラル | 重要な役割 | 供給源と注意点 |
|---|---|---|
| **鉄 Fe** | ヘモグロビン・ミオグロビンなどに関与 | 肉・魚、貝、豆、青菜。ヘム鉄と非ヘム鉄では吸収率が異なり、ビタミンCや食事全体が影響 |
| **亜鉛 Zn** | 酵素・免疫・味覚・細胞分裂 | 牡蠣、肉、魚、卵、豆。サプリメントの高用量摂取は銅不足の原因になり得る |
| **銅 Cu** | 鉄の利用、酵素反応、結合組織 | 貝、レバー、ナッツ、豆。亜鉛過剰との相互作用に注意 |
| **マンガン Mn** | 酵素反応、骨・結合組織の代謝 | 穀類、豆、ナッツなど。食品からの不足は通常まれ |
| **ヨウ素 I** | 甲状腺ホルモンの構成 | 海藻、魚介、卵。昆布などの過剰摂取は甲状腺機能に影響し得る |
| **セレン Se** | 抗酸化関連酵素、甲状腺ホルモン代謝 | 魚、肉、卵、穀類。高用量サプリや特定食品への偏りに注意 |
| **クロム Cr** | 糖代謝への関与が研究されてきた | 肉・穀類など。日本の基準にはあるが、人体での必須性は国際的に議論がある |
| **モリブデン Mo** | 尿酸等の代謝に関わる酵素の構成 | 豆、穀類、納豆など。不足は通常まれ |

### 7-3　「鉄が多い食品」と「鉄を使える食事」は違う

鉄は代表的な例である。牛肉や赤身魚に含まれるヘム鉄は、植物性食品の非ヘム鉄より一般に利用されやすい。非ヘム鉄の吸収は、ビタミンCや肉・魚を同じ食事で取ることによって改善することがある。反対に、茶・コーヒーのポリフェノールや一部食品のフィチン酸は条件によって非ヘム鉄の吸収を抑える。だからといって茶や全粒穀物を一律禁止する必要はない。鉄不足が問題となる人は、食事内容と飲むタイミングの両方を見直す。

月経の有無で必要量は変わる。2025年版では、18〜29歳女性の鉄の推奨量は月経なし**6.0mg/日**、月経あり**10.0mg/日**。貧血を疑う症状がある場合は、食事評価だけで自己診断せず検査で原因を確認する。

### 7-4　海藻を「ミネラルの万能供給源」と考えない

わかめ、海苔、昆布は同じ海藻でも栄養素の濃度が大きく異なる。料理に使う乾物の重量はごく少量の場合もある一方、昆布のヨウ素は少量でも非常に多くなり得る。**「海藻を毎日大量に食べれば健康」という推論は危険**。特に甲状腺疾患がある人は個別の医療上の判断が必要になる。

# 第8章　吸収・相互作用・調理：栄養素の足し算が成立しない理由

「成分表に記載された量＝体内に利用された量」という前提は成り立たない。代表的な相互作用を整理する。

| 組み合わせ・条件 | 起きること | 献立への落とし込み |
|---|---|---|
| **非ヘム鉄＋ビタミンC** | 吸収を助ける | 豆料理にパプリカ・ブロッコリー・柑橘などを加える |
| **カルシウム＋ビタミンD** | ビタミンDがカルシウムの腸管吸収調節に関わる | 乳製品・骨ごと食べる魚に加え、魚類等でDも確保 |
| **カロテノイド＋適量の脂質** | 吸収が改善する場合がある | 緑黄色野菜を少量の油で調理 |
| **葉酸＋B12** | 正常なDNA合成・造血に両方が重要 | 葉物・豆と、魚・卵・乳製品等を適切に組み合わせる |
| **多量の亜鉛サプリ＋銅** | 銅の吸収・状態を悪化させ得る | サプリの重ね飲みを避ける |
| **フィチン酸＋鉄・亜鉛** | 吸収を妨げる場合がある | 豆・穀物の浸水・発酵や、食事の多様性で対応 |
| **シュウ酸＋カルシウム** | カルシウム利用を妨げる場合がある | ほうれん草だけをカルシウム源として過信しない |
| **煮る・ゆでる＋水溶性成分** | ゆで汁に移行することがある | 短時間加熱、蒸し調理、汁ごと使う料理などを選ぶ |
| **油・光・酸素＋脂質** | 酸化が進む条件になり得る | 油の保存、繰り返し加熱を見直す |

調理は悪いことばかりではない。加熱によって食品の安全性が高まり、消化性が改善し、一部の成分が利用しやすくなる。野菜は「生が常に上」「加熱が常に上」ではない。栄養素と調理目的によって最適解が変わる。

食品成分表を使うときは、**生／ゆで／焼き、可食部100g当たり、缶汁を含むか、乾物／水戻し、廃棄部分**を確認する。たとえば乾燥わかめ100gの成分値を、水で戻したわかめ100gや小鉢一杯の摂取量として扱うのは重大な計算ミスである。

# 第9章　教材を読んだ上で、特に訂正・補足すべき16点

| 教材から受け取りやすい印象 | 科学的に補うべき理解 |
|---|---|
| ①「33種類の必須栄養素がある」 | 33は教材で数える評価項目。分類は重複し、過剰抑制項目もある |
| ②「PFC比率が理想なら健康」 | ビタミン・ミネラル・食物繊維・脂肪酸の質は別途確認する |
| ③「炭水化物は脳に必要＝砂糖を食べるべき」 | 脳のブドウ糖利用と、砂糖摂取の必要性は別 |
| ④「たんぱく質が入っている食材なら同じ」 | 量、必須アミノ酸、消化・吸収、エネルギー不足の有無が違う |
| ⑤「脂質はなるべく減らす」 | 必須脂肪酸、細胞膜、脂溶性ビタミン吸収のため必要。量と質を調整 |
| ⑥「植物油なら全て不飽和脂肪酸が多い」 | ココナッツ油など、飽和脂肪酸が多い植物油もある |
| ⑦「n-6系は悪い脂肪酸」 | 必須脂肪酸であり、一般化して排除するべきでない |
| ⑧「ビタミンは体内で作れない」 | Dの皮膚合成、ナイアシンの体内合成など例外がある |
| ⑨「にんじんのビタミンAで視力がよくなる」 | 欠乏による視覚障害の予防と、近視の改善は別。βカロテンは前駆体 |
| ⑩「抗酸化ビタミンは多いほどよい」 | サプリの大量摂取が健康利益を増やすとは限らない |
| ⑪「ビタミンKを増やせば血液が固まりやすく健康」 | 正常な凝固機能に必要だが、多く摂ればよい意味ではない。服薬に注意 |
| ⑫「桜えび・牛乳・小魚を食べればカルシウムは十分」 | 実際の量、魚の骨を食べるか、吸収率を考慮する |
| ⑬「ほうれん草は鉄・カルシウム源なので完璧」 | 非ヘム鉄・シュウ酸など、利用効率と一食の摂取量を考慮する |
| ⑭「海藻＝ミネラルだから大量に食べるほどよい」 | 種類と量によってヨウ素過剰の問題がある |
| ⑮「梅干し・塩・みそでナトリウム補給」 | ナトリウムは必須でも、日本の食生活では過剰に注意することが多い |
| ⑯「成分表の100g値が高い食品が最高」 | 現実的な一食量、調理損失、吸収率、費用、継続性まで比較する |

これは「教材は間違いだらけ」という意味ではない。**基礎教材が説明を簡略化した箇所を、実際の食事評価で誤らないよう精密化した**ものである。

# 第10章　献立を科学的に評価する手順

## 10-1　まず分量をそろえる

献立を評価するとき、材料名だけでは不十分。米を何g食べるのか、豚肉は脂身の多い部位か、油は何gか、野菜は何gか、塩やしょうゆは何mlかを決める。食品成分表で数値を確認し、エネルギー・PFC・食物繊維・優先ミネラルを計算する。

そのうえで、献立の「不足リスク」と「過剰リスク」を切り分ける。健康な成人の普通の食事なら、**たんぱく質、食物繊維、カルシウム、鉄（必要性に応じる）、ビタミンD、食塩、飽和脂肪酸**が実務上の点検対象になりやすい。ただし年齢・性別・身体状況が違えば優先順位も変わる。

## 10-2　3つの料理を診断してみる

**例A：ご飯＋豚バラ白菜炒め。** ご飯は炭水化物、豚肉はたんぱく質・ビタミンB1、白菜は野菜由来の成分を供給する。ただし豚バラの量によっては脂質と飽和脂肪酸が増え、野菜量・食物繊維・カルシウム・ビタミンDは不足し得る。豚バラの一部を赤身肉・豆腐に替える、きのこや青菜を加える、別の食事で魚・乳製品を取り入れるなどで改善できる。

**例B：たこ・きゅうり・しそ・梅の和え物。** たこにはたんぱく質など、しそには微量栄養素、きゅうりには水分、梅には酸味がある。ただし、しそは1〜数枚程度では成分表100g当たりの高さほどの栄養貢献は期待できない。梅干しは塩分が高い製品もあり、この小鉢だけでエネルギーやカルシウムまで満たせるわけではない。**優秀な副菜でも、完全な一食ではない**。

**例C：塩むすびだけの節約ごはん。** 安く、炭水化物は確保しやすいが、たんぱく質・脂質・食物繊維・カルシウム・ビタミンなどが乏しい。納豆、卵、豆腐、冷凍青菜、魚缶などを加えれば、少ない工程で栄養密度を改善できる。食費だけでなく「不足している栄養素をいくらで補えるか」を考える。

## 10-3　予算と手間を抑える基本構成

買い置きの候補として、米・押し麦、卵、豆腐、納豆、魚缶、冷凍ブロッコリー・小松菜、旬の野菜、牛乳・ヨーグルト、果物を考える。これらは比較的幅広い栄養素を組み合わせやすく、作業時間や保存性の面でも使いやすい。価格は時期や店舗で変わるため、**安い＝常に同じ食材**ではない。

一日の例は、朝に「ご飯・卵・納豆・青菜」、昼に「ご飯・鶏肉と野菜の炒め物・果物」、夜に「ご飯・骨ごと食べる魚缶・豆腐・野菜汁」、間食や食事に「牛乳またはヨーグルト」を取り入れる構成。これは食品選択の考え方を示した例で、**分量を指定して栄養計算した完成献立ではない**。この例だけで全栄養素の充足を保証しない。

# 第11章　「健康そうに見える」を超えるチェックリスト

| 評価軸 | チェックする質問 | よくある落とし穴 |
|---|---|---|
| エネルギー | 生活活動と食事量が釣り合っているか | 低カロリーを常に善とみなす |
| たんぱく質 | 1日何gか、料理中にどの程度含まれるか | 肉・卵があるだけで「十分」と判定 |
| 脂質 | 総量、飽和脂肪酸、魚由来脂肪酸はどうか | 植物油・ナッツなら無制限と考える |
| 炭水化物 | 主食の量、糖類偏重、食物繊維はどうか | 糖質を減らすこと自体を目的化 |
| 微量栄養素 | 鉄・カルシウム・D・葉酸・C等をどう確保するか | 彩りだけで判断する |
| 吸収・調理 | 調理法、ゆで汁、可食部、組み合わせを考えたか | 生100g値を調理後の小鉢に当てる |
| 過剰リスク | 塩分、飽和脂肪酸、サプリ高用量はどうか | 「体にいい」成分なら多いほどよい |
| 現実性 | 味・価格・時間・保存性・満足感はどうか | 続けられない献立を理想とみなす |

**評価の原則：** 単品の料理だけで「完璧」かどうかを判定しない。一食で欠けた栄養素を、ほかの食事や数日間の食品選択でどう補うかを考える。ただし、極端な低エネルギーや不十分なたんぱく質が慢性化している場合は「週のどこかで補うからよい」として放置しない。

# 第12章　病気・薬・ライフステージが変わるとルールも変わる

ここまでの議論は、主に健康な一般成人を想定している。以下では専門的な評価が優先される。

**腎機能が低下している場合：** カリウム、リン、たんぱく質、水分、食塩などの考え方が変わる。食品の多様性を増やす一般論を機械的に適用しない。

**妊娠前後：** 葉酸の追加摂取や鉄、ヨウ素、ビタミンAの過剰など、重点が変わる。特にレバー由来のレチノールやサプリメントの重複に注意する。

**高齢者：** 食欲低下、咀嚼・嚥下、低栄養、筋肉量の低下などを踏まえる。PFC比率だけでなく、実際に必要なエネルギーとたんぱく質を確保できるかが重要。

**完全菜食：** ビタミンB12の信頼できる供給源の確保が必須の論点となる。鉄、亜鉛、カルシウム、ビタミンD、EPA・DHAなども食品選択と必要に応じた補助を検討する。

**薬を使用している場合：** ワルファリンとビタミンK、特定の薬剤とミネラルなど、相互作用がある。食事を大幅に変えたりサプリを開始したりする前に医師・薬剤師へ確認する。

**疲労・動悸・息切れ・しびれなどが続く場合：** 栄養素不足だけが原因とは限らない。自己判断の鉄剤や大量サプリではなく、適切な受診・検査が必要になる。

# 終章　栄養学で実際に身につけるべき判断力

食品を「たんぱく質の食品」「ビタミンの食品」と一対一に分類するのは出発点としてよい。しかし現実の食事は、一つの食品が複数の栄養素を供給し、一つの栄養素が複数の食品から入る、相互作用のある仕組みでできている。

献立を考えるときに問うべきことは、次の四つに集約できる。

1. **どれだけ食べるか。** 量とエネルギーを数量化する。
2. **身体にどれだけ届くか。** 調理、消化・吸収、食品の組み合わせを考える。
3. **足りないもの・多すぎるものは何か。** 不足と過剰の両側から見る。
4. **続けられるか。** おいしさ、価格、手間、満腹感、文化的・個人的な好みを尊重する。

**「栄養価が高い」だけでは、よい献立とは言えない。必要な栄養を、過剰な負担なく、継続して得られる献立がよい献立である。**
