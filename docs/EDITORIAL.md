# 編集の約束

このサイトを長く続けるための、書くときの約束です。

## いちばん大事なこと

**実際に作った記録と、想像上の設定を混ぜない。**

- 開催していない回を、開催済みとして載せない。
- 食べていない感想、言っていない発言を書かない。
- 撮っていない写真を載せない。AI生成画像を、実際の料理写真として載せない。
- 確認していないURLを載せない。確認できない手順・分量は「確認中」にするか、書かない。

テーマの例（「たとえば」）を載せるときは、例であることがわかるように書く。

## 欄としるし

| 欄 | しるし | 中身 |
| --- | --- | --- |
| 01 今夜の誰か | 想像 | その号の「誰か」の設定。実在の人物ではない |
| 02 今夜の献立 | 献立 | 何を作ったか |
| 03 なぜこの料理なのか | 解説 | 世界観・時代背景・生活条件と献立の関係 |
| 04 レシピ | 資料 | 材料・作り方・参考資料（確認できたものだけ） |
| 05 ふたりの食卓 | 記録 | 実際の写真と感想 |
| 06 編集後記 | 記録 | 自由な感想、発見、失敗 |

段落の先頭に付けるしるし：

| しるし | 使いどころ |
| --- | --- |
| 【史実】 | 史料や研究で確かめられていること |
| 【推定】 | 史料にもとづいて推し量ったこと |
| 【再現】 | 現代の台所で再現するために置き換えたこと |
| 【創作】 | 想像で補ったこと |
| 【伝承】 | 言い伝え・慣習として伝わっていること |
| 【設定】 | ファンタジーなどの世界の設定 |
| 【記録】 | 実際にやってみたこと |

## ジャンルごとの約束

### 昔の人

- 史実、史料にもとづく推定、現代での再現、創作を区別する。
- 当時存在しなかった食材や調理法を、根拠なく使わない。置き換えたときは【再現】で理由を書く。
- 参考にした本・論文・サイトは `sources` に書く。

### 海外の宗教

- 食文化の背景にある信仰、禁忌、生活習慣を尊重する。
- 同じ宗教でも、地域、宗派、個人によって違いがあることを前提に書く。「〇〇教徒は皆～」と書かない。
- 文化を奇妙なもの・面白いものとして消費しない。

### ファンタジー

- 創作は自由。
- ただし作品世界の中で、食料の調達、保存、調理設備には一貫した筋を通す。

### 現代人

- 社会的背景や生活条件から食卓を想像する。
- 職業、国籍、性別などで安易に決めつけない。

## 人について

- 参加者の個人名やプロフィールは、本人の許可なく載せない。
- 台所は「台所A」「台所B」と呼ぶ（`src/site.config.ts` で変更できる）。

## 外部のレシピについて

- レシピの文章や写真を丸ごと転載しない。料理名・出典・リンクを示す。
- リンクは実際に開いて確認したものだけ。
