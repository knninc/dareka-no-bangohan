# デザインの考え方

料理ブログではなく、**毎週一冊の小さな雑誌**として作っています。日本の週刊誌の表紙、文芸誌の組版、リソグラフ印刷の ZINE、フィールドノートを混ぜた方向性です。

## 色：紙に三色刷り

リソグラフ（孔版）の二色刷り・三色刷りを下敷きにしています。紙のクリームに、墨・朱・藍。

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--paper` | `#f4eee2` | 紙。うっすらノイズを重ねて地合いを出す |
| `--paper-2` | `#eae1cf` | 色上質紙・帯 |
| `--ink` | `#1f1c18` | 墨（本文） |
| `--ink-2` | `#4f4940` | 二次テキスト（紙上 7.7:1） |
| `--shu` / `--shu-text` | `#c8381f` / `#b3321b` | 朱。「週刊」の判、記録のしるし、強調 |
| `--ai` | `#263e73` | 藍。想像のしるし、リンク |

ジャンルごとにインクを1色持たせています（すべて紙の上で 6:1 以上）。

| ジャンル | 印 | 色 |
| --- | --- | --- |
| 現代人 | 今 | 藍 `#2a447e` |
| 昔の人 | 昔 | 柿渋 `#86461f` |
| ファンタジー | 幻 | 苔 `#2e6243` |
| 海外の宗教 | 祈 | 葡萄 `#6b3560` |

宗教のジャンルに特定の宗教を連想させる色（サフランなど）を当てないよう、中立的な葡萄色にしています。

## 書体

- **明朝（Shippori Mincho B1）** が主役。見出しは極太 800、本文は 500。
- **ゴシック（Zen Kaku Gothic New）** は小さなラベルとナビゲーションだけ。
- **等幅（IBM Plex Mono）** は号数・日付などのメタ情報。フィールドノートの書き込みのように。

## 組版

- 本文は行間 1.9、字間 0.04em、行長は全角 34 字前後。
- 見出しは `palt`（プロポーショナル詰め）、`word-break: auto-phrase` で文節改行。
- 表紙・号の扉の題は**縦組み**。半角の数字や略語は縦中横・正立に自動で整形（`src/lib/tate.ts`）。
- スマートフォンでは横組みに切り替える（縦組みの長文を横スクロールさせない）。

## 写真がないとき

写真がないことを隠さず、「記録待ち」として見せます。表紙は皿の線画と献立で成立するようにしています。AI生成画像で埋めません。

## アクセシビリティ

- 文字色はすべて WCAG AA（4.5:1）以上。
- スキップリンク、見出し階層、`aria-current`、フォーカス表示。
- 装飾（判子・皿・トンボ）は `aria-hidden`。
- `prefers-reduced-motion` で動きを止める。
- JavaScript なしですべての機能が動く。
