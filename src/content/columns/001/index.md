## 食べ物当てクイズではない

肉と魚と卵は、たんぱく質。油とナッツは、脂質。米とパンと芋は、炭水化物。野菜と果物は、ビタミン。牛乳と小魚と海藻は、ミネラル。

学校で習うこの分け方は、入口としてはとても便利です。でも、そのまま晩ごはんに当てはめると、ときどき間違えます。

たとえば、ほうれん草には鉄が含まれています。けれど、それが鉄のもととして足りるかどうかは、どれだけ食べたか、どれだけ吸収されたかで変わります。

食べものが身体の役に立つまでには、順番があります。

1. どれだけ食べたか
2. 調理のあとに、どれだけ残っているか
3. どれだけ消化され、吸収されたか
4. 身体の中で、どう使われたか
5. それで足りているのか、多すぎるのか

栄養学は、食べものの名前を五つの箱に振り分ける遊びではありません。**身体に届く量を見積もる学問**です。

## 「33」は、必須栄養素の数ではない

五大栄養素の下に、33の項目を数える数え方があります。たんぱく質がひとつ、脂質のなかまが四つ、炭水化物のなかまが二つ、ビタミンが十三、ミネラルが十三。

ただし、これは「33種類をぜんぶ増やしましょう」という意味ではありません。

- 飽和脂肪酸のように、むしろ**摂りすぎに気をつけたい**項目も入っています。
- 食物繊維は大切ですが、足りないと特定の欠乏症が出る、昔ながらの意味での「必須栄養素」とは少し違います。
- クロムのように、人にとって必須かどうか、国際的に議論が残っているものもあります。
- そして、生きるのに欠かせない**水**は、この33に入っていません。

## 数字は、いつも「誰か」の数字

厚生労働省の「日本人の食事摂取基準（2025年版）」には、いくつもの数字が並んでいます。読むときに大事なのは、数字ごとに意味が違うことです。

| 名前 | どんな数字か |
| --- | --- |
| 推定平均必要量 | その集団の、およそ半数の人が必要量を満たす量 |
| 推奨量 | その集団の、ほとんどの人が必要量を満たすと見込まれる量 |
| 目安量 | 必要量を十分に推定できないときに置く量 |
| 目標量 | 生活習慣病の予防を考えて、目指す量 |
| 耐容上限量 | 摂りすぎの害を避けるための量。目指す数字ではない |

推奨量の半分しか摂れなかった日に、すぐ欠乏症になるわけではありません。目安量を少し超えたら危ない、というものでもありません。上限量まで摂るほど健康になる、というのは、いちばん危ない読み方です。

どの数字も、ある年齢と性別の**集団**を前提にしていて、ひとりの人の診断値ではありません。

たとえば、18〜29歳の女性に必要なエネルギーの参考値は、身体活動レベルが「低い／ふつう／高い」で、1日1,700／1,950／2,250kcal。同じ年齢でも、暮らし方で数百kcal変わります。

このサイトでは毎週、ひとり「誰か」を想像しています。1000年前の農民も、遠い国の修道士も、存在しない世界の魔女も、疲れ切った現代人も。表に並んでいるのは、その誰か本人の数字ではなく、どこかにいる、たくさんの誰かの数字です。

## 栄養素は、足し算にならない

成分表に書いてある量が、そのまま身体に入るわけではありません。組み合わせや調理で、届く量が変わります。

- **豆や青菜の鉄と、ビタミンC**　植物性の食品の鉄（非ヘム鉄）は、ビタミンCや肉・魚と同じ食事でとると、吸収がよくなることがあります。
- **緑黄色野菜と、少しの油**　カロテノイドは、適量の脂質と一緒だと吸収がよくなる場合があります。
- **ゆでる**　水に溶けやすい成分は、ゆで汁に移ることがあります。
- **ほうれん草と、カルシウム**　シュウ酸がカルシウムの利用を妨げる場合があるので、ほうれん草だけをカルシウムのもととして当てにしないほうがいい。

乾燥わかめ100gの数字を、水で戻したわかめの小鉢一杯に当てはめると、大きな計算違いになります。成分表は「生か、ゆでたか」「可食部100gあたりか」まで確かめて読むものです。

## 創刊号の晩ごはんを、栄養で語れるか

創刊号の献立は、Cook Do の八宝菜、トマたま、梅しらす大葉の冷奴でした。

この晩ごはんの栄養を、数字で言うことはできません。記録に、材料のグラム数も、油の量も、ごはんの量も書いていないからです。料理の名前や写真だけでは、「たんぱく質が足りている」とも「塩分が多い」とも決められません。

言えるのは、表の読み方の練習くらいです。

- トマたまは、トマトと卵を油で炒める料理です。カロテノイドと油の話を思い出します。
- 梅干しには塩分の多い製品もあり、合わせ調味料も食塩のもとになります。日本の食事では、ナトリウムは足りないことより、摂りすぎのほうが問題になりやすい栄養素です。
- 豆腐は、カルシウムのもとのひとつに数えられています。

どれも「そういう場合がある」という話で、あの夜、ふたりの身体に何が届いたのかは、わかりません。

## よい晩ごはんの、四つの問い

献立を考えるときの問いは、四つにまとめられます。

1. どれだけ食べるか。
2. 身体にどれだけ届くか。
3. 足りないもの、多すぎるものは何か。
4. 続けられるか。

四つ目の「続けられるか」には、おいしさ、値段、手間、おなかの満ち方、文化や好みまでが入っています。栄養価が高いだけでは、よい献立とは言えません。

疲れ切った夜に、合わせ調味料で八宝菜をつくる。それも、四つ目の問いへのひとつの答えなのかもしれません。

このサイトは、健康のための献立をつくっているわけではありません。特に目的はありません。

それでも、誰かの晩ごはんを想像するとき、その人の身体のことも、ほんの少しだけ想像してみる。そのくらいの距離で読むと、栄養の表は、けっこうおもしろい読みものです。
